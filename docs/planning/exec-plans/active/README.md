# Active Execution Plans

이 디렉터리에는 현재 진행 중이거나 곧 진행할 실행 계획 문서를 둔다.

## 규칙

- 파일명은 작업 목적이 드러나야 한다
- 큰 작업은 하나의 문서로 관리한다
- 상태가 바뀌면 계획 문서도 같이 갱신한다
- 완료되면 `../completed/`로 이동한다

## 예시

- `dispatch-api-mvp.md`
- `billing-inquiry-scenario.md`

## 현재 상태

- `spring-boot-foundation.md`는 완료되어 `../completed/`로 이동했다
- 새 active plan은 Phase 2 작업 범위가 정리되면 추가한다
