# Phase 1 Plan 01

## 이름

Project Bootstrap

## 목표

FlowMind 백엔드 프로젝트의 기본 뼈대를 만든다.

## 범위

- `backend/` 디렉터리 생성
- Spring Boot 프로젝트 초기화
- Gradle 또는 Maven 구조 확정
- 기본 패키지 네이밍 결정
- 최소 실행 엔트리포인트 추가

## 완료 기준

- 백엔드 프로젝트가 독립적으로 빌드 가능하다
- 애플리케이션 시작 클래스가 존재한다
- 이후 설정/스토리지 작업이 자연스럽게 이어진다

## 리스크

- 초기 구조를 과하게 잡으면 변경 비용 증가
- 패키지 네이밍을 서둘러 정하면 나중에 재정리 필요

## 보완 필요 항목

- `com.flowmind` 기준 패키지 네임 확정
- Gradle 멀티모듈 여부 판단
- backend 단독 README 필요 여부 판단
