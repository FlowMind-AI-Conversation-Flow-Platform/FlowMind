# Execution Plan Template

## 제목

작업 이름을 명확하게 적는다.

## 목표

- 이번 작업이 해결할 문제

## 범위

- 이번에 포함하는 작업

## 비범위

- 이번에 하지 않는 작업

## 예상 변경 파일

- 생성 파일
- 수정 파일
- 참고 파일

## 리스크

- 설계 충돌 가능성
- 데이터 영향
- 테스트 부족 가능성

## 작업 단계

1. 분석
2. 설계
3. 구현
4. 검증
5. 문서 정리

## 검증 기준

- 성공 조건
- 실패 조건
- 확인 명령 또는 테스트 방법

## 진행 상태

- `pending`
- `in_progress`
- `completed`
