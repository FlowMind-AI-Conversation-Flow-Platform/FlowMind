# FlowMind Portfolio Checklist

## 목적

이 문서는 실제 포트폴리오 제작 직전에 빠뜨린 것이 없는지 확인하기 위한 체크리스트다.

## 프로젝트 설명

- 한 줄 소개가 명확한가
- 어떤 문제를 해결하는지 설명 가능한가
- 왜 하이브리드 구조를 택했는지 설명 가능한가

## 구현 증빙

- 실행 가능한 코드가 있는가
- health endpoint 또는 실행 화면이 있는가
- deterministic 시나리오 증빙이 있는가
- LLM fallback 증빙이 있는가
- 로그 / trace 증빙이 있는가

## 운영 관점

- fallback reason을 설명할 수 있는가
- prompt file 구조를 보여줄 수 있는가
- metrics 또는 analytics 예시가 있는가

## 자료 준비

- 캡처 또는 GIF가 있는가
- README가 최신 상태인가
- 이력서 bullet이 준비됐는가
- 면접 답변 포인트가 정리됐는가

## 최종 확인

- 현재 상태와 미래 계획을 혼동해서 쓰지 않았는가
- 구현한 것과 설계한 것을 구분해서 설명하는가
