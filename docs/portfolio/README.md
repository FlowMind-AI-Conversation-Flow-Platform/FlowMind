# FlowMind Portfolio Docs

## 목적

이 폴더는 FlowMind를 나중에 포트폴리오 프로젝트로 정리할 때 직접 참고하는 문서 묶음이다.

목표는 단순하다.

- 이 폴더만 읽어도 프로젝트를 설명할 수 있을 것
- 이력서, 포트폴리오 페이지, 면접 답변에 바로 쓸 재료가 정리되어 있을 것
- 구현이 진행되면서 어떤 증빙을 남겨야 하는지 추적할 수 있을 것

## 사용 방식

- 프로젝트 설명이 필요하면 `project-summary.md`부터 본다
- 기술 선택 이유를 설명해야 하면 `tech-decisions.md`를 본다
- 구현 후 무엇을 캡처/기록해야 하는지 확인하려면 `implementation-evidence.md`를 본다
- 면접 대비는 `interview-points.md`를 본다
- 이력서 문장 초안은 `resume-bullets.md`를 본다
- 포트폴리오 최종 제작 전 점검은 `portfolio-checklist.md`를 본다
