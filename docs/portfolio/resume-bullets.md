# FlowMind Resume Bullets

## 이력서용 짧은 문장 초안

- Intent 기반 시나리오 처리와 LLM fallback을 결합한 하이브리드 대화 플랫폼 FlowMind를 설계
- Java/Spring Boot 기반 고객 응대 백엔드 아키텍처와 phase 기반 실행 문서 체계를 수립
- deterministic scenario, slot filling, dispatch trace, prompt 운영 구조를 포함한 실무형 대화 시스템 설계

## 구현 후 강화 버전 초안

- Spring Boot 기반 하이브리드 대화 플랫폼을 구현하여 Intent 기반 시나리오 처리와 LLM fallback을 분리 운영
- Slot filling, session context, dispatch trace를 적용해 대화 흐름의 예측 가능성과 추적 가능성을 확보
- prompt file 기반 템플릿 관리와 route/latency 기록 구조를 설계해 품질 개선 가능한 운영 기반 마련

## 포지션 맞춤형 강조 포인트

### AI / 챗봇 / 콜봇 직무

- 인텐트 기반 대화 구조 설계
- LLM 프롬프트와 fallback 구조 설계
- 로그와 품질 지표 기반 운영 개선

### 백엔드 직무

- Spring Boot 아키텍처 설계
- 설정/스토리지/도메인 경계 분리
- 운영 가능한 로그/추적 구조 설계
